Grapify 🕸️

A simple Graph Data Structure Visualization tool
-------------------------------------------------------------------------------------------------------------------
📌 Overview

Grapify is an interactive web application that allows you to visualize graphs in real-time.
Currently, it supports:

• ➕ Adding nodes

• ➖ Deleting nodes

This project aims to make understanding graph data structures more intuitive by providing a visual and interactive representation. Future enhancements will include edges, traversal algorithms, and weighted graphs.
-------------------------------------------------------------------------------------------------------------------
🚀 Features

• Add Nodes – Click or use the UI controls to add nodes to the graph.

• Delete Nodes – Select and remove nodes with a simple action.

• Interactive Canvas – Nodes are displayed dynamically with smooth visualization.

• Support weighted graphs
-------------------------------------------------------------------------------------------------------------------
🛠️ Tech Stack

• Frontend: React.js, react-flow
